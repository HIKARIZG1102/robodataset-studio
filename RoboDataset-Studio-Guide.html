RoboDataset Studio 采集流程教程

本文说明当前 V2 UI 的完整数据采集流程。软件只监听外部 ROS2 topic，不启动相机、GELLO、follow 或机器人控制节点。

0. 启动前准备

先在外部终端启动需要的数据源，例如 RealSense 相机、WidowX 驱动、GELLO 控制节点。软件只负责发现 topic、生成 YAML、监听采集、Review、转换和上传。

cd /home/microsate/robotarm_control_ws/ROBODATASET/robodataset-studio
./RoboDataset-Studio.sh

1. 配置与 ROS Topic

Project 页

控件作用
Task name任务/项目名称。会参与 YAML 命名和数据目录命名。
Version数据版本，例如 v1。为空时 UI 保持空，运行目录会使用安全默认值。
Operator采集人员，可留空。
Dataset root采集输出根目录。注意这不是 YAML 配置库目录。
Browse选择输出根目录。
Use gello_widowx preset填入旧数据集常用示例路径和任务名。
Save Project保存项目字段到本机上次使用状态，并同步到 Config 页。

Discovery 页

控件作用
Refresh ROS Graph刷新当前 ROS2 nodes/topics/services。
Topic 勾选框选择要记录的 topic。应勾选图像 topic 和需要的 JointState topic。
Generate Config From Selected Topics根据勾选 topic 生成 listener-only YAML。只使用勾选项，不自动偷选其它 topic。

Inspector 页

控件作用
Node info / Echo / Hz手动检查选中 node/topic 的信息、单帧消息、发布频率。
Image monitor选择图像 topic 后预览画面。用于确认图像是否流畅、是否黑屏、topic 是否正确。

Config 页

控件作用
Refresh Config From Selected Topics用 Discovery 当前勾选 topic 重新生成 YAML，并保留表单里可编辑字段。
Reload Form From YAML用下方 YAML 覆盖表单显示。YAML 为空字段会清空表单对应字段。
Apply Form To YAML把表单字段局部写回 YAML，保留 YAML 中其它结构。
Validate检查 YAML 是否缺少必要结构或违反 listener-only 约束。
Save YAML Library仅保存到工程相对路径 config_library/*.yaml。不会提前写入数据集 session 目录。
Saved YAML / Load YAML从 config_library 读取旧 YAML。
Rename YAML / Delete YAML管理配置库里的 YAML。
Default prompt后台生成 AI 配置匹配提示词，包含当前 YAML、表单、勾选 topic、topic echo/node info 和标准 schema。
Send把 AI prompt 发送到 Settings 中配置的 OpenAI-compatible 模型。
Replace YAML From AI Preview把 AI 预览中的 YAML 显式替换到主 YAML。不会自动覆盖。

YAML 配置库固定在 RoboDataset Studio 工程相对目录 config_library/。采集 session 里的 collection_config.yaml 只会在点击 Start Recording 后写入。

2. 采集页

控件作用
Saved YAML选择配置库里的 YAML。Config 页保存新 YAML 后，此处会同步刷新。
Load YAML载入选中 YAML，刷新监听计划和图像监控。
Refresh Listener Plan按当前 YAML 刷新 streams 表、预计输出数量和监控窗口。
Check Nodes后台检查配置 topic：topic info、echo once、topic hz。不会阻塞前端。
Stop mode选择采集停止方式：Manual、Duration、Sample count。
DurationDuration 模式显示，按秒数采集。
SamplesSample count 模式显示，按同步样本数采集。
Start Recording开始后台 ROS2 监听采集。开始时会把当前配置快照写到本次 session 的 collection_config.yaml。
Stop RecordingManual 模式下请求停止；recorder 会在当前同步样本完成后退出。
Simulate Listener Episode生成 mock 数据，用于测试 UI 流程，不使用真实 ROS2 topic。

采集模式

  • Manual：只显示采集帧率提示，不显示时长和样本数。开始后手动点 Stop Recording 结束，不显示预计 episode 数。
  • Duration：只显示 Duration 输入。预计 duration × sample_rate_hz 个同步样本，若有 action，transition 数约为样本数减 1。
  • Sample count：只显示 Samples 输入。按指定同步样本数采集，若有 action，transition 数约为样本数减 1。

建议流程：Load YAML -> Check Nodes -> 确认监控画面 -> 选择 Stop mode -> Start Recording -> 完成后进入 Review。

3. 数据 Review

控件作用
Scan Episodes扫描当前 session 的 training/episode_*.npz。
Quality report统计黑帧、白帧、缺字段、action 维度等问题。
Scan CALVIN Layout扫描 raw/merged 数据集布局。
Inspect HDF5查看转换后的 HDF5 摘要。

4. 数据转换

Convert 页用于把 raw session 合并到 CALVIN-like merged 目录，并生成 HDF5。HDF5 会把 metadata 放入 attrs，训练数组只保留核心字段。

5. 上传

Upload 页用于配置 SSH 目标、预览远端目录、创建文件夹、上传数据集并做 manifest 校验。密码不会保存到 profile。

数据格式说明

每个 YAML 映射一份未来数据格式。核心字段由 dataset.core_schema 描述：

  • 图像核心键：rgb_static、rgb_wrist、rgb_overhead、额外 rgb_*
  • 状态核心键：robot_obs
  • 动作核心键：rel_actions、actions
  • 扩展字段：depth、metadata、timestamp、camera_info 等

严格 CALVIN loader 应只读取配置中的 core keys；RoboDataset metadata 字段可忽略或剥离。
