RoboDataset Studio V3 操作流程与按键说明

本文记录 V3 从配置、ROS topic 选择、真实采集、Review、Convert 到 Upload 的完整操作顺序。V3 默认是 listener-only：只监听 ROS2 topic 采集数据，不主动向机器人发布控制命令。

0. 启动前准备

  1. 外部终端启动相机，使图像 topic 正常发布，例如 /camera/camera/color/image_raw、/camera/camera_wrist/color/image_raw。
  2. 外部终端启动 WidowX 驱动，使 /wx250s/joint_states 正常发布。
  3. 如果用 GELLO 手操 WidowX，外部启动 GELLO 和 follow 节点。Studio 只记录状态和图像，不负责控制机器人。
  4. 启动 Studio： 
    cd /home/microsate/robotarm_control_ws/ROBODATASET/robodataset-studio-v3
./RoboDataset-Studio-V3.sh

1. 从零创建项目并采集真实 episode

1.1 新建或打开项目

  1. 点击顶部 File。它不是下拉菜单，会在左侧打开 Projects 项目栏。
  2. 在项目栏点击 New Project 新建项目，或 Open Project Folder 从已有项目目录打开。打开目录时默认从上一次打开项目的父目录开始；第一次使用时默认从 Studio 的 robodataset/projects 开始。
  3. 也可以右键项目列表中的项目，选择 Open Project、Properties、Current Project Config、Rename、Delete、Permanent Delete 等操作。
  4. Delete 会把项目目录移动到同级 .deleted_projects，列表中消失但磁盘数据仍可找回；Permanent Delete 会弹出警告确认，并直接从磁盘永久删除该项目目录。
  5. 新建项目时填写项目名、版本、operator、项目根目录，选择一个配置库条目或先留空。
  6. 创建或打开后，顶部会显示 Project / Config / recorded|editable 摘要，底部状态栏会常驻显示当前 Project folder；项目打开后固定出现 Properties、Collect、Review、Convert、Upload 五个核心标签页，这些标签页不能关闭。

1.1.1 Properties 页查看项目结构

  1. 打开项目后进入 Properties 标签页。
  2. 上方显示项目名、版本、配置 ID、是否已有记录数据、项目路径、目录大小、修改时间和当前真实目录结构。
  3. 目录结构会用 |--、`-- 分支显示当前实际内容，不再显示固定 expected structure。
  4. raw_sessions/session_* 只显示到 session 层，并用文件/目录数量摘要表示内部内容；merged/export 数据目录同样只显示到数据集目录层，避免 episode 文件刷屏。
  5. 项目页会监听项目目录变化，并定时检查目录签名；采集、转换、导出、删除文件后，大小和结构会自动刷新。
  6. 下方目录树展示项目内 raw_sessions、exports、review、logs 等实际结构。
  7. 点击 .yaml、.json、.txt、.md 文件，右侧会只读预览内容。

1.2 刷新 ROS 图并选择 topic

  1. 点击窗口右上角 Refresh Nodes/Topics。
  2. 点击顶部 Config。它不是下拉菜单，会在左侧打开 Configs 配置栏。
  3. 在配置栏双击配置进入 Config Library；也可以右键配置进行 Open Config、Duplicate、Rename、Delete、New。
  4. 进入 ROS Topics 标签页，展开 topic 分组。
  5. 勾选本次要记录的 topic，例如：
    • /camera/camera/color/image_raw [sensor_msgs/msg/Image]
    • /camera/camera_wrist/color/image_raw [sensor_msgs/msg/Image]
    • /wx250s/joint_states [sensor_msgs/msg/JointState]
  6. 点击 Refresh config from selected topics，根据已选 topic 同步生成 streams/state/action。
  7. 点击 Apply form -> YAML，把表单内容写入 total_config.yaml。
  8. 点击 Save 保存配置库条目。如果当前项目已经绑定此配置，项目会同步刷新。

1.3 用 AI 辅助补配置

  1. 先在 Settings -> Settings 中启用 AI，填写 base URL、API key、model。
  2. 回到 Config Library -> AI Match Config。独立 AI Assist 页面已移除，AI 功能集中在配置库和 Review 内。
  3. 点击 Default prompt。如果 topic probe 失败或 prompt 超预算，界面会提示，不会静默发送坏 prompt。
  4. 点击 Send 发送给模型。
  5. 确认 AI 预览 YAML 没问题后，点击 Replace dataset_config from AI preview 显式替换 dataset_config。
  6. 点击 Save 保存配置。

1.4 采集真实 episode

  1. 进入 Collect 标签页。
  2. 点击 Refresh Listener Plan，确认当前 dataset_config 中 streams/state/action 正确。
  3. 点击 Check Nodes，检查 topic info、echo once、hz。
  4. 选择 Stop mode：
    • Manual：手动点 Start/Stop，适合真实手操。
    • Duration：按秒数自动结束。
    • Sample count：按同步样本数自动结束。
  5. 点击 Start Recording 开始采集。此时会按当前时间创建新的 session 目录。
  6. 手操 WidowX 做需要的动作，例如抬起、放下、开合夹爪。
  7. Manual 模式下点击 Stop Recording。完成后 Collect 页会显示最后完成的 session 路径。

2. Review 数据是否正常

  1. 进入 Review 标签页。
  2. 先看 Overview 页。左侧显示当前项目目录树，包括 raw session、merge/export、review report、yaml 等；点击 yaml/json/txt 文件可在右侧预览。
  3. 进入 Episode Review 页，点击 Use Current Session，或点击 Browse 选择 raw session 根目录。
  4. 点击 Scan Session 扫描 episode。
  5. 点击 Run Local Checks 检查字段、shape、黑白帧、action/state 等质量问题。
  6. 点击 episode 表格中的某一行，下方 Selected NPZ Details 会显示该 episode 的字段和摘要。
  7. 用 Status filter 过滤 ok/warning/error/uncheck。
  8. 用 Manual mark 选择 good/bad/uncertain/unmarked，然后点击 Mark Selected 标记。
  9. 确认坏数据后可点击 Delete Selected，数据会移动到 review_deleted。
  10. 点击 Export Quality Report 导出质量报告。

3. Convert：合并 session 或导出 HDF5

  1. 进入 Convert 标签页。
  2. 点击 Browse 选择 Raw sessions root，通常是项目下的 raw_sessions。
  3. 点击 Scan Sessions。所有 session 默认勾选。
  4. 可用 Select All、Clear、Invert 快速选择，也可以在 Use 列拖动批量勾选/取消。
  5. 填写 Output dir 和 Output name。如果目标同名，系统会自动生成防撞名称，例如 calvin_2.hdf5。
  6. 点击 Merge Sessions 合并为 CALVIN-like 目录，或点击 Convert To HDF5 导出 HDF5。
  7. 任务完成后回到 Review 的 Overview 或 HDF5 Inspect 页检查结果。旧的 CALVIN Layout 页已经移除。

4. Upload：上传数据

  1. 上传服务器的 host、port、username、key path 来自当前项目 total_config 的 upload 字段，页面里不可随意改。
  2. 密码只在 Upload 页临时输入，不会写入配置文件。
  3. 进入 Upload 标签页后，点击 Reload from project config 同步服务器信息。
  4. 在 File or folder 选择要上传的本地文件或目录。
  5. 点击 Check Dependencies 检查 rsync/ssh 等依赖。
  6. 点击 Build Manifest 生成临时本地 manifest。
  7. 点击 Verify Local Manifest 检查本地文件。
  8. 填写或选择 Remote directory，点击 Connect and list 浏览远端目录。
  9. 可用 Up、路径面包屑、Create Folder 选择远端目录。
  10. 点击 Start rsync upload 上传。
  11. 中断后可点击 Repair / Resume verified upload 续传修复。
  12. 上传后点击 Verify remote manifest 校验远端文件。

5. Settings：语言、缩放、AI

控件作用
Language选择 English 或 中文。保存后菜单、主流程按钮、标签页和主要表格标题会即时切换。
Zoom In菜单 Settings -> Zoom In，快捷键 Ctrl++ 或 Ctrl+=。
Zoom Out菜单 Settings -> Zoom Out，快捷键 Ctrl+-。
Reset Zoom菜单 Settings -> Reset Zoom，快捷键 Ctrl+0。
Enable AI启用 OpenAI-compatible AI 功能。
Refresh models检测当前 base URL/API key 能访问的模型列表。

6. Inspector、Logs、Help 和分屏

6.1 Inspector

  1. 点击顶部 Inspector 打开或隐藏全局检查器。Inspector 是固定的 dock 面板，不会被工作区分屏替换。
  2. Topic Inspector 可查看 node/topic info、echo、hz。
  3. Image Monitor 可选择当前 ROS 图里的 image topic，也会保留项目配置里的多个 image topic，例如 static、wrist、depth 图像流。
  4. 点击 Monitor project image 会优先使用当前选中的可监视 image topic；如果当前选择不可用，才回退到项目配置中的第一个 image topic。

6.2 Logs

  1. 点击顶部 Logs。它不是下拉菜单，会打开日志/任务侧边栏。
  2. File、Config、Logs 三个侧边栏默认合并在左侧同一个 dock tab 组里；点击哪个顶部入口，就切到哪个侧栏。只有手动拖动 dock 标签后，才会分离成独立分屏。
  3. 侧边栏列出当前后端任务；双击任务会打开 Logs 标签并定位到该任务。
  4. Logs 标签左侧同时列出任务和项目中的日志文件，右侧显示任务详情、运行 logs、result，或日志文件内容。

6.3 Help / About

  1. Help -> Tutorial 打开本操作指南。
  2. Help -> About 查看 RoboDataset Studio V3、开发者名单、版权和项目用途信息。

6.4 工作区分屏和合并

  1. 右键任意工作区标签页，可选择 Split Left、Split Right、Split Up、Split Down 把当前页面拆到新 pane。
  2. 最多同时存在 3 个工作区 pane。Inspector 仍然保持在 dock 区域，不参与替换。
  3. 右键标签页选择 Merge All Panes 可把所有工作区 pane 合并回一个。
  4. 拖动分隔条可调整各 pane 大小；窗口缩放时页面会保留滚动条和自适应布局。

7. 常用任务按键顺序速查

任务按键顺序
新建采集配置File -> Projects 侧边栏 -> New Project -> Refresh Nodes/Topics -> Config -> Configs 侧边栏 -> 打开 Config Library -> ROS Topics 勾选 -> Refresh config from selected topics -> Apply form -> YAML -> Save
真实手操采集Collect -> Refresh Listener Plan -> Check Nodes -> Stop mode: Manual -> Start Recording -> 手操机器人 -> Stop Recording
检查刚采 sessionReview -> Overview 看项目树 -> Episode Review -> Use Current Session -> Scan Session -> Run Local Checks -> 点击 episode 行查看详情 -> Mark Selected 或 Delete Selected
导出 HDF5Convert -> Browse raw_sessions -> Scan Sessions -> 勾选 sessions -> 设置 Output name -> Convert To HDF5
上传服务器Upload -> Reload from project config -> Browse local file/folder -> Check Dependencies -> Build Manifest -> Connect and list -> Start rsync upload -> Verify remote manifest
查看任务日志Logs -> 日志侧边栏双击任务 -> Logs 页右侧查看 task logs/result

如果 ROS graph 看不到 topic，先检查外部驱动是否启动、ROS_DOMAIN_ID/RMW 是否一致、topic 是否真的发布。Studio 只发现和监听已有 topic。

推荐每次真实采集后立即 Review 一遍，确认图像、robot_obs、rel_actions 都存在，再继续大批量采集。
