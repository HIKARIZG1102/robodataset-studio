RoboDataset Studio V3 操作流程与按键说明

本文记录 V3 从配置、ROS topic 选择、真实采集、Review、Convert 到 Upload 的完整操作顺序。V3 默认是 listener-only：只监听 ROS2 topic 采集数据，不主动向机器人发布控制命令。

0. 启动前准备

  1. 外部终端启动相机，使图像 topic 正常发布，例如 /camera/camera/color/image_raw、/camera/camera_wrist/color/image_raw。
  2. 外部终端启动 WidowX 驱动，使 /wx250s/joint_states 正常发布。
  3. 如果用 GELLO 手操 WidowX，外部启动 GELLO 和 follow 节点。Studio 只记录状态和图像，不负责控制机器人。
  4. 启动 Studio： 
    cd /home/microsate/robotarm_control_ws/ROBODATASET/robodataset-studio-v3
./RoboDataset-Studio-V3.sh

1. 从零创建项目并采集真实 episode

1.1 新建或打开项目

  1. 菜单点击 File -> New Project，或 File -> Open Project 打开已有项目。
  2. 新建项目时填写项目名、版本、operator、项目根目录，选择一个配置库条目或先留空。
  3. 创建或打开后，顶部会显示 Project / Config / recorded|editable 摘要。

1.2 刷新 ROS 图并选择 topic

  1. 点击窗口右上角 Refresh Graph。
  2. 打开 Config -> Config Library。
  3. 进入 ROS Topics 标签页，展开 topic 分组。
  4. 勾选本次要记录的 topic，例如：
    • /camera/camera/color/image_raw [sensor_msgs/msg/Image]
    • /camera/camera_wrist/color/image_raw [sensor_msgs/msg/Image]
    • /wx250s/joint_states [sensor_msgs/msg/JointState]
  5. 点击 Refresh config from selected topics，根据已选 topic 同步生成 streams/state/action。
  6. 点击 Apply form -> YAML，把表单内容写入 total_config.yaml。
  7. 点击 Save 保存配置库条目。如果当前项目已经绑定此配置，项目会同步刷新。

1.3 用 AI 辅助补配置

  1. 先在 Settings -> Settings 中启用 AI，填写 base URL、API key、model。
  2. 回到 Config Library -> AI Match Config。
  3. 点击 Default prompt。如果 topic probe 失败或 prompt 超预算，界面会提示，不会静默发送坏 prompt。
  4. 点击 Send 发送给模型。
  5. 确认 AI 预览 YAML 没问题后，点击 Replace dataset_config from AI preview 显式替换 dataset_config。
  6. 点击 Save 保存配置。

1.4 采集真实 episode

  1. 进入 Collect 标签页。
  2. 点击 Refresh Listener Plan，确认当前 dataset_config 中 streams/state/action 正确。
  3. 点击 Check Nodes，检查 topic info、echo once、hz。
  4. 选择 Stop mode：
    • Manual：手动点 Start/Stop，适合真实手操。
    • Duration：按秒数自动结束。
    • Sample count：按同步样本数自动结束。
  5. 点击 Start Recording 开始采集。此时会按当前时间创建新的 session 目录。
  6. 手操 WidowX 做需要的动作，例如抬起、放下、开合夹爪。
  7. Manual 模式下点击 Stop Recording。完成后 Collect 页会显示最后完成的 session 路径。

2. Review 数据是否正常

  1. 进入 Review 标签页。
  2. 在 Episode Review 页点击 Use Current Session，或点击 Browse 选择 raw session 根目录。
  3. 点击 Scan Session 扫描 episode。
  4. 点击 Run Local Checks 检查字段、shape、黑白帧、action/state 等质量问题。
  5. 点击 episode 表格中的某一行，下方 Selected NPZ Details 会显示该 episode 的字段和摘要。
  6. 用 Status filter 过滤 ok/warning/error/uncheck。
  7. 用 Manual mark 选择 good/bad/uncertain/unmarked，然后点击 Mark Selected 标记。
  8. 确认坏数据后可点击 Delete Selected，数据会移动到 review_deleted。
  9. 点击 Export Quality Report 导出质量报告。

3. Convert：合并 session 或导出 HDF5

  1. 进入 Convert 标签页。
  2. 点击 Browse 选择 Raw sessions root，通常是项目下的 raw_sessions。
  3. 点击 Scan Sessions。所有 session 默认勾选。
  4. 可用 Select All、Clear、Invert 快速选择，也可以在 Use 列拖动批量勾选/取消。
  5. 填写 Output dir 和 Output name。如果目标同名，系统会自动生成防撞名称，例如 calvin_2.hdf5。
  6. 点击 Merge Sessions 合并为 CALVIN-like 目录，或点击 Convert To HDF5 导出 HDF5。
  7. 任务完成后回到 Review 的 HDF5 Inspect 或 CALVIN Layout 页检查结果。

4. Upload：上传数据

  1. 上传服务器的 host、port、username、key path 来自当前项目 total_config 的 upload 字段，页面里不可随意改。
  2. 密码只在 Upload 页临时输入，不会写入配置文件。
  3. 进入 Upload 标签页后，点击 Reload from project config 同步服务器信息。
  4. 在 File or folder 选择要上传的本地文件或目录。
  5. 点击 Check Dependencies 检查 rsync/ssh 等依赖。
  6. 点击 Build Manifest 生成临时本地 manifest。
  7. 点击 Verify Local Manifest 检查本地文件。
  8. 填写或选择 Remote directory，点击 Connect and list 浏览远端目录。
  9. 可用 Up、路径面包屑、Create Folder 选择远端目录。
  10. 点击 Start rsync upload 上传。
  11. 中断后可点击 Repair / Resume verified upload 续传修复。
  12. 上传后点击 Verify remote manifest 校验远端文件。

5. Settings：语言、缩放、AI

控件作用
Language选择 English 或 中文。保存后菜单、主流程按钮、标签页和主要表格标题会即时切换。
Zoom In菜单 Settings -> Zoom In，快捷键 Ctrl++ 或 Ctrl+=。
Zoom Out菜单 Settings -> Zoom Out，快捷键 Ctrl+-。
Reset Zoom菜单 Settings -> Reset Zoom，快捷键 Ctrl+0。
Enable AI启用 OpenAI-compatible AI 功能。
Refresh models检测当前 base URL/API key 能访问的模型列表。

6. 常用任务按键顺序速查

任务按键顺序
新建采集配置File -> New Project -> Refresh Graph -> Config Library -> ROS Topics 勾选 -> Refresh config from selected topics -> Apply form -> YAML -> Save
真实手操采集Collect -> Refresh Listener Plan -> Check Nodes -> Stop mode: Manual -> Start Recording -> 手操机器人 -> Stop Recording
检查刚采 sessionReview -> Use Current Session -> Scan Session -> Run Local Checks -> 点击 episode 行查看详情 -> Mark Selected 或 Delete Selected
导出 HDF5Convert -> Browse raw_sessions -> Scan Sessions -> 勾选 sessions -> 设置 Output name -> Convert To HDF5
上传服务器Upload -> Reload from project config -> Browse local file/folder -> Check Dependencies -> Build Manifest -> Connect and list -> Start rsync upload -> Verify remote manifest

如果 ROS graph 看不到 topic，先检查外部驱动是否启动、ROS_DOMAIN_ID/RMW 是否一致、topic 是否真的发布。Studio 只发现和监听已有 topic。

推荐每次真实采集后立即 Review 一遍，确认图像、robot_obs、rel_actions 都存在，再继续大批量采集。
